## 小结
三个 P0 的修改汇总：

问题 文件 修改内容 P0-1 warmup key 永不命中 store.py key 从 "today" → today_str() 真实日期；删除未使用的 import time P0-2 append 去重硬编码 store.py GROUP BY symbol, date → _pk_columns() 动态读取主键列 P0-3 Client 未消费预热数据 client.py 5 个方法（ kline / limit_up / market_breadth / northbound_flow / market_pb / dragon_tiger ）加 Store 读写 + 故障降级直连兜底

降级兜底的统一模式 ：

```
if self.store:
    try:
        return self.store.get_or_fetch(...)  # 优先缓存
    except Exception:
        logger.warning(...)                   # Store 坏了也不炸
return self.source.xxx(...)                  # 回退直连
```
这样即使 .stoke_cache.db 文件损坏或磁盘满了，系统照样能从数据源拉取，不会瘫痪。
