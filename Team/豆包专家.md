新增免费 / 开源 A 股数据源（个人量化首选）
以下 6 个完全免费且稳定，可直接补充到你的sources目录：
efinance
特点：整合了新浪 / 网易 / 东方财富的公开接口，返回标准 DataFrame，内置重试机制
限制：实时延迟 15 秒，无调用次数限制（合理频率）
安装：pip install efinance
最佳：基金数据、可转债数据、龙虎榜数据（akshare 覆盖不全的部分）
pytdx
特点：比 mootdx 更轻量的通达信接口，无需安装客户端，直接连接券商服务器
限制：仅支持 Level-1 行情，历史数据最多 5 年
最佳：替代 mootdx 作为备用实时行情源
TickFlow
特点：2026 年新出的免费历史数据工具，无需注册，直接获取全市场日 K 线
限制：仅支持日线数据，无实时行情
安装：pip install tickflow
最佳：快速回测、批量获取全市场历史数据
巨潮资讯 API
特点：官方信披平台，所有上市公司公告 / 财报 / 分红数据 100% 准确
限制：免费版每日 1000 次调用，需实名认证
最佳：财务数据校验、公告事件驱动策略
新浪财经 API
特点：实时延迟 < 10 秒，支持港股 / 美股
限制：反爬极严，每分钟最多 10 次请求
最佳：备用实时行情源（仅低频使用）
国家统计局 API
特点：官方宏观数据（GDP/CPI/PPI/ 工业增加值），完全免费
限制：更新滞后 1-2 个月
最佳：宏观策略、行业景气度分析
