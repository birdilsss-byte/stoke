核心价值：实时性远超 akshare 爬虫，适合盘中异动监控，作为腾讯直连的高阶补充
4. GroundAPI

核心价值：无需安装重型 Python 库，一个 API Key 覆盖行情 + 情绪 + 资讯，适合轻量脚本调用
